# Executive Brief — D&M Deal Portal

## What Is This Application?

The D&M Deal Portal is an internal web application for D&M Auto Leasing that manages the full lifecycle of vehicle financing deals — from agent submission through manager review, underwriter evaluation, lender forwarding, and final delivery. It replaces manual processes (email, spreadsheets, phone calls) with a structured workflow that enforces SLA timers, document requirements, and audit trails.

## Business Problem

D&M Auto Leasing operates across 9 office locations (Fort Worth, Dallas, Houston, Austin, Dallas Lease Returns, and four "Four Stars" dealerships). Sales agents submit vehicle deals that must be reviewed by managers, evaluated by underwriters, and forwarded to lenders for approval. Without this system, deals are tracked informally, documents are lost, kickbacks lack structured reasons, and there is no visibility into bottlenecks or SLA compliance. This portal centralizes every deal into a single, role-aware system with real-time status tracking.

## Intended Users

| Role | Count | What They Do |
|------|-------|-------------|
| **Agent** | Many (per office) | Submit new vehicle deals via a 7-step wizard, upload documents, respond to kickbacks |
| **Manager** | 1 per team | Review submitted deals, approve or kick back to agent, forward to underwriting |
| **General Manager** | Few | Cross-office deal oversight and management |
| **Underwriter** | Small team | Claim deals, evaluate creditworthiness, approve or kick back to manager, forward to lenders |
| **Executive** | Few | Read-only access to all deals, reporting dashboards |
| **Administrator** | 1-2 | Full system access, user management, role switching for debugging |

## Current Status

**This application is in a demo/staging state.** It is deployed on Vercel with a Supabase backend, but it is NOT in production with real users or real deal data. Test accounts exist in the Supabase Auth system. The core deal submission and review workflow is functional. Reporting dashboards are built but operate on test data. Two planned modules (Finance Printing, Wire Request) are not yet built.

## Tech Stack Summary

The application is built with Next.js 14 (React 18, TypeScript) using the App Router pattern with server-side rendering. The backend is Supabase, which provides PostgreSQL with Row Level Security, authentication, real-time subscriptions, and file storage. The UI uses Tailwind CSS with a custom D&M brand theme. Validation uses Zod schemas. The app is deployed to Vercel via GitHub, with a SonarCloud integration for code quality scanning. There are no API routes — all data mutations go through Next.js Server Actions. Test coverage exists for utility functions, permissions, and validation schemas (Vitest), but no integration or end-to-end tests exist.
